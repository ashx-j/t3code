# Classic composer

A web-only plugin that brings back the composer row from before T3's redesign. The model, effort and
permissions pickers sit on the left, each ending in a chevron, and attach, other plugins' composer
buttons and send sit on the right in T3's order, 16px in from the card's edges. Below a 640px wide
window, the row and the prompt both sit 12px in. Full access shows an open lock. The pickers keep
their width, so as the composer narrows, permissions and then effort drop their labels, and on the
narrowest screens the row hands over to T3's own row, which folds them into a menu. A new thread's
workspace and branch sit in a drawer tucked under the card, shaded below the card in dark mode. A
folder without git gives the drawer nothing to show, so there is no drawer, and while T3's own row
shows, the drawer names the permissions.

First build its web half with `vp run build:examples` in `packages/plugin-sdk`. Then install it
by dragging this folder onto **Settings → Plugins**, or with **Add plugin → Choose folder**.
Turning it off brings back T3's current composer.

It uses `api.ui.replace("composer.controls", …)`, so it only arranges T3's own pickers and buttons.
Build again after editing `web.tsx`.

## What it hardcodes

The row's layout and folding steps only touch the plugin's own elements. The rules below reach
into T3's markup because T3 has no seam for them, each through the most stable hook it has. If T3
renames a hook, that rule stops matching and T3's own look shows in its place. When T3 adds the
seam, move the rule to it.

The chevron and open lock are copies of Lucide's `chevron-down` and `lock-open` paths, drawn as CSS
masks, until T3 shares its icons.

The drawer's corners read Tailwind's `--radius-2xl`. Tailwind emits that token only while T3's own
code uses it, so it falls back to T3's value. A theme token list in the SDK would replace it.
